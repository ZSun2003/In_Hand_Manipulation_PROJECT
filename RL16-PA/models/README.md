# RL16-PA 模型归档

本目录统一存放该机械手的原始工程模型和基本仿真源网格。

| 类型 | 数量 |
| --- | ---: |
| SolidWorks 零件 `.SLDPRT` | 30 |
| SolidWorks 装配 `.SLDASM` | 11 |
| STL 网格 | 14 |

- `cad/`：原 SolidWorks 文件及工程子目录；装配与零件关系保留。`~$` 锁文件属于 SolidWorks 临时状态，已清除。
- `simulation/`：按 `translation` / `rotation` 用途存放基本仿真网格。
- `SHA256SUMS`：上述实体模型文件的 SHA-256 校验清单，用于验证归档传输完整性。

代码目录的 `mesh` 是相对符号链接，指向本目录的对应实体模型。复制/检出归档时须保留链接；不要将本目录与代码拆开移动。不同仿真用途中的同名模型按原版本保留，未进行内容合并。

在本目录校验模型文件：

```bash
shasum -a 256 -c SHA256SUMS
```

XML 仍位于对应代码目录，定义模型装配、关节和执行器配置。本目录不含策略权重、训练日志或生成的训练数据。
